## ✨ 功能特性

- **真实星图**：12 星座取真实亮星（RA / Dec / 视星等）+ 标准连线，非手绘示意图
- **2D / 3D 双视角**：2D 呼吸星图；3D 为 Three.js 穹顶星场——拖动旋转 / 双指缩放 / 缓速自转，星星独立闪烁、连线呼吸脉动
- **生日 → 星座** 自动判定，也可直接点选星座
- **专属星图**：运势四维、星座档案、今日星语
- **星座合拍**：元素关系 + 合拍度环形仪表 + 随机样例一键体验
- **小红书分享卡**：Canvas 1080 × 1440（3:4），星座大字星图卡 / 双星座合拍卡
- **移动优先 + 桌面增强**：手机上是单列沉浸流；≥1000px 宽屏自动切换双栏阅读版式

## 🎨 视觉语言

整体走**亮雾暖白 + 星座专属色**（每星座由 JS 注入 `--accent`），反对"塑料感"：

- **2D 星图**：星星 = 柔晕 + 十字细芒 + 亮核，CSS 逐星独立呼吸闪烁
- **3D 星图**（高定珠宝 / 香氛大片质感）：
  - 星星是**碎钻细闪**：芒短而柔、核圆润如珍珠高光，暗星只是温柔光点
  - 连线是**香槟金包丝**（向暖金收敛 80%），像首饰勾线而非霓虹管
  - 星星色泽统一叠 30% 珠光暖白；星座主题色只留给最亮星的光晕 → 克制
  - 星尘 = 香槟金粉 + 远层淡薰衣草雾，叠加珍珠色**柔焦散景光斑**
  - 画面上再叠一层 **珠光雾面滤镜**（顶部月光 + 底部低饱和雾），呼吸更慢更慵懒
- 移动端配色克制低饱和；文案口语、温暖，语气贴近"星座同好"

## 🗂 目录结构

```
cyber-zodiac-signs/
└── web/
    ├── index.html          单页入口（首页 / 专属星图 / 星座合拍 / 分享弹层）
    ├── css/
    │   ├── base.css        设计系统 · 组件 · 桌面增强（≥1000px 双栏）
    │   └── signs.css       星座主题 · 2D 星图动画 · 3D 画布珠光滤镜
    └── js/
        ├── vendor/         three.min.js + OrbitControls（本地，无 CDN）
        ├── data.js         12 星座档案 · 真实亮星星表 · 主题色派生（hex → accent / 星夜渐变）
        ├── mock.js         本地确定性引擎：生日判定 / 运势 / 合拍计算
        ├── star-svg.js     2D 星座星图渲染（与 3D / 分享卡共用投影数据）
        ├── star-3d.js      Three.js 3D 星场（穹顶投影 · 珠光材质 · 氛围层）
        ├── share.js        分享卡 Canvas 绘制（1080×1440，水印可配置）
        └── app.js          视图路由 / 主题注入 / 交互
```

## 🔌 架构要点

| 模块 | 说明 |
|---|---|
| 数据层 `data.js` | `CONSTELLATIONS_ACCURATE` 存真实星表；`themeOf()` 由星座 hex 派生 accent 深浅 / 三段星夜渐变 / RGB |
| Mock 引擎 `mock.js` | `hash` + 确定性 `rng`，`signOf` 判定星座、`fortuneFor` 当日运势、`matchFor` 元素合拍分 |
| 2D 星图 `star-svg.js` | `prepare2D()` 统一投影 + 缓存，供 2D / 3D / 分享卡三端复用 |
| 3D 星场 `star-3d.js` | 把 2D 平面点印上鼓起的虚拟天球；程序化生成星芒 / 光晕 / 金粉纹理；`breathe()` 注册呼吸动画；`prefers-reduced-motion` 下自动关闭自转 |
| 分享 `share.js` | Canvas 1080×1440；`window.SHARE_CFG` 可配置品牌名 / slogan / 引流账号（`handle`） |
| 主题系统 | 星座色经 `applyTheme()` 写入 `body` 的 CSS 变量，渐变 1s 过渡切换 |

## 🧪 隐私与降级

- 完全本地运行，**不联网、不上传任何数据**；`localStorage` 仅存本地打开次数计数（`xy_stats`），不上报
- 无 WebGL / Three.js 加载失败时，3D 按钮自动提示并回落 2D
- `prefers-reduced-motion` 用户自动关闭 3D 自转与 2D 闪烁

## 📦 已知边界

- 3D 星图为轻量 WebGL 场景，超低端设备建议保留 2D
- 分享卡 Canvas 依赖本地字体渲染，不同系统字形微差属正常
